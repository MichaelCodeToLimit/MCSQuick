Your own Minecraft server, in a few questions.

A free, open-source setup tool for Minecraft Java servers. It asks simple questions, downloads Java and the server for you, and gives you start scripts and an address friends can join. Windows, Mac and Linux, in 14 languages.

DownloadView on GitHub

Heads up: this tool is new. It has not been tested on every system, and some parts (for example Geyser downloads, the Mac and Linux versions, and some translations) have only been checked in simulation. If something breaks, please open an issue on GitHub.

What it does

Simple or Advanced

Simple asks a handful of questions. Advanced lets you choose everything, including the server version.

Vanilla or Paper

Plain Minecraft, or Paper for plugins and better performance. Optional Velocity proxy.

Java + Bedrock

Optional Geyser and Floodgate so phone and console players can join too.

Free tunnels

A step-by-step guide for playit.gg (or ngrok), so friends can join without port forwarding. Port forwarding and UPnP are supported too.

Plugins and mods

Pick popular plugins and mods from a list, and change them later.

Change it later

A second script edits an existing server: settings, version, plugins. It makes a backup first.

14 languages

English, 中文, हिन्दी, العربية, עברית, Español, Français, Deutsch, Português, Русский, 日本語, 한국어, Türkçe, Italiano, with right-to-left support.

Everything automatic

Downloads Java, creates start and stop scripts, can start with your computer, and handles online or offline mode.

Download

Pick your system and install method. We highlighted the one for your system. Files come from the latest release.

Untested packages: the zips and tar.gz were tried in simulation only. The .deb, .rpm, AppImage, Flatpak, AUR, Homebrew and Nix packages are new and have not been tried on real systems yet. The AUR and Nix files are in the repo's packaging folder and are not published to those stores.

How it works

  1. Download and unpack the file for your system, then start it (see above).
  2. Choose your language, then Simple or Advanced.
  3. Name your server, pick the version, and say whether Bedrock players should be able to join.
  4. Choose how friends connect: a playit.gg tunnel (easiest), or port forwarding.
  5. Wait while it downloads Java and the server. Then use the start script it creates.
  6. Later, run mc-customize to change settings, version or plugins.

FAQ

What is a playit.gg tunnel?

A free service that gives your server a public address without touching your router. The tool walks you through creating the account and tunnel step by step. Bedrock players need a second (UDP) tunnel, and the guide covers that too.

Do I need port forwarding?

Not if you use a tunnel. Port forwarding opens port 25565 (and 19132 for Bedrock) on your router. The tool can try UPnP for you, but not every router allows it.

Online mode or offline mode?

Online mode checks that players own Minecraft and is safer. Offline mode lets anyone join with any name, which is risky on a public server. The tool defaults to online mode.

Are Bedrock players supported?

Yes, through Geyser and Floodgate on Paper. Bedrock names get a "." prefix by default, and Bedrock needs UDP port 19132.

Is it safe? Does it phone home?

No trackers. It downloads Java and server software from their official sources, and nothing else. The scripts are plain text, so you can read them before running.

Windows or macOS says it can't open the file.

That is the normal warning for unsigned downloads. On Mac, right-click then Open. On Windows, choose More info, then Run anyway.
